# 📊 Sales Data Analysis using Python
## 📌 Overview
This project analyzes retail sales data using Python. It performs data analysis with Pandas and visualizes category-wise sales using Matplotlib to identify sales trends and top-performing categories.
## 🎯 Objectives
- Analyze sales data using Python.
- Group sales by product category.
- Identify the best-performing category.
- Visualize sales using a bar chart.
- Practice data analysis with Pandas and Matplotlib.
## 🛠️ Tools & Libraries Used
- Python
- Pandas
- Matplotlib
## 📂 Dataset
The dataset contains the following columns:
- Region
- Category
- Sales
## 🔍 Analysis Performed
- Loaded sales data into a Pandas DataFrame.
- Calculated total sales for each category.
- Identified the highest-selling category.
- Created a bar chart for category-wise sales visualization.
## 📈 Key Insights
- Clothing recorded the highest sales.
- Electronics and Groceries generated similar sales.
- The bar chart provides a clear comparison between product categories.
